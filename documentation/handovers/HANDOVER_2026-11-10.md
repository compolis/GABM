## Local calibration evidence (completed)

Profiles tested:

- Baseline: `0.2 / 0.2 / 0.3 / 0.3`
- Conservative: `0.08 / 0.10 / 0.45 / 0.12`
- Mid: `0.12 / 0.14 / 0.38 / 0.18`

Observed pattern:

- Baseline tends to over-shift toward positive outcomes.
- Conservative reduces drift strongly and may over-dampen dynamics.
- Mid profile appears to provide a better balance and preserves normal > awkward separation.

## Suggested immediate next steps

1. Run a small Calder pilot with the **mid** profile for both:
   - normal mode
   - awkward/max_dissimilarity mode
2. Compare local vs Calder aggregate metrics:
   - `final_mean_opinion`
   - `delta_mean_opinion`
   - `final_opinion_gap`
3. If alignment is acceptable, adopt mid profile as default calibration candidate for downstream CAG work.
