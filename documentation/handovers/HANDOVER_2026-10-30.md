## Main objective in progress

Establish practical reproducibility behavior for local/HPC LLM serving (Qwen3-14B first), including:

1. Same-instance determinism (fixed seeds).
2. Cross-initialization determinism (fresh server start).
3. Diversity under seed-window ensembles.
4. Concurrency/stress behavior and practical ceiling.

## Notes and caveats

- Current reproducibility testing intent is live inference behavior; concurrent launcher defaults to no-cache mode.
- Exact reproducibility may not be guaranteed even with fixed seeds; release evidence should report exact-match rates and practical stability, not only binary pass/fail.
- Comparison utilities support job IDs and explicit run paths.
